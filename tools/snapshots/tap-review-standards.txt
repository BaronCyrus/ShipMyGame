# 小游戏审核规范
# 1. 基本说明
# 1.1 法律法规
1.1.1 所有小游戏必须符合中国法律法规，未经国家新闻出版广电总局批准的移动游戏不得在大陆地区上线运营，无版号游戏不得包含内购计费内容。
1.1.2 游戏资质不允许互相套用，版号出版时间需晚于软著出版时间。
1.1.3 游戏内容不得包含违法或敏感信息，如涉政、涉赌、暴力、血腥、虐待动物或儿童、淫秽、色情、性暗示等。
1.1.4 游戏不得侵犯他人合法权益，包括著作权、商标权、肖像权、名誉权等。
1.1.5 游戏不得对武器进行过于逼真的描述，或宣扬违法使用武器。
1.1.6 游戏不得包含反政府、反社会或不符合主流政治的内容。
1.1.7 游戏不得存在安全隐患、鼓动犯罪、扰乱社会秩序等行为。
# 1.2 游戏内付费
1.2.1 游戏内付费必须明码标价，明确告知用户可享受的服务。
1.2.2 游戏不得存在诱导付费行为，如诱导站外充值、线下交易、二维码赞助等。
1.2.3 游戏不得存在自动扣费行为。
1.2.4 在小游戏平台使用支付功能的，应当依照法律、法规等规范性文件的规定开展，不得实施非法吸收公众存款、集资诈骗等违法犯罪行为，或为违法犯罪行为提供协助。
1.2.5 内购小游戏停止运营时需提交下架申请
为确保内购小游戏在停止运营时充分保障用户合法权益，妥善处理用户争议，开发者需严格按照法律法规与监管政策要求，提前7日向用户进行周知，并在开发者平台提交下架申请。以下是详细的下架流程申请指南：
1.2.5.1 申请下架流程
1.2.5.1.1 填写《下架申请》
进入开发者平台，点击【工单】-【创建工单】
问题类型：游戏下架申请
选择申请的厂商和需要下架的游戏
页面提交下架申请，需提供以下材料：
下架原因
期望下架的时间
营业执照扫描件或资质证明材料（附件提供）
1.2.5.2 用户权益保障
提前通知：
在游戏内设置下架公告，明确告知用户下架时间及补偿方案，确保用户充分知情。
公告需在用户每日首次登录后强制弹出，持续7天。
补偿方案：
针对已充值用户，需制定合理的补偿方案，如退款、转移游戏内资产等，确保用户权益不受损害。
争议处理：
如因下架引发用户争议，开发者需及时响应并妥善处理，避免损害用户合法权益。
1.2.5.3 法律责任
赔偿责任：
如因小游戏停止运营及下架事宜损害任何第三方（包括但不限于游戏著作权人、游戏联运方、用户）的合法权益，由开发者承担全部赔偿责任。
合规运营：
开发者需确保下架流程符合国家法律法规及平台政策要求，避免因违规操作引发法律风险。
1.2.6 含内购功能的小游戏必须持有《网络游戏出版物号》（ISBN格式：999-9-9999-9999-1），且版号主体需与运营公司一致。
# 1.3 游戏内广告及捆绑下载
1.3.1 游戏不得存在空白广告位或主要目的为展示广告。
1.3.2 游戏广告不得模仿系统通知或提示诱导用户点击。
1.3.3 游戏广告不得在应用关闭或后台运行时依然存在。
1.3.4 游戏不得存在无法关闭的悬浮窗或弹窗广告。
1.3.5 游戏广告不得捆绑下载其他应用。
1.3.6 游戏不得强制用户下载其他应用或游戏。
1.3.7 广告信息需显著标明"广告"。
1.3.8 游戏启动页不得默认勾选下载其他应用。
1.3.9 游戏未经用户许可不得自动下载其他应用。
1.3.10 Banner广告高度≤屏幕10%，不得遮挡操作按钮，且需提供用户可随时关闭的明显按钮（如"×"标识）。
1.3.11 Banner广告必须固定在游戏界面非核心操作区域（如顶部或底部边缘），禁止遮挡游戏按钮、角色血条、任务提示等关键交互区域；
1.3.12 激励广告不得以虚假奖励诱导点击（如"100%必得道具"需与实际概率一致）
1.3.13 激励广告播放期间需允许用户随时关闭，关闭后仍可正常返回游戏界面。
1.3.14 插屏广告仅允许在游戏自然断点（如关卡结束、角色死亡复活前）触发，禁止在战斗过程、任务对话中强制弹出；
# 1.4 游戏重复
1.4.1 不得上传内容相似或相同的游戏。
1.4.2 游戏新版本主体功能不得与旧版本相差过大。
1.4.3 游戏不得为简单网站页面打包或套用模板。
1.4.4 游戏主要功能不得依赖第三方应用或跳转至网页。
1.4.5 游戏内容不得与已收录游戏相同，如发现被侵权请进行申诉，点击查看侵权投诉流程。
# 1.5 欺诈行为
1.5.1 游戏存在欺诈、误导用户的行为将被下架，严重者会被封禁账号。
1.5.2 游戏在审核前后通过服务端控制应用内容，在上架后开启违规服务将被下架，严重者会被封禁账号。
# 1.6 暂不收录游戏
1.6.1 非官方包、破解、盗版、未授权游戏。
1.6.2 赌博类、博彩类、实物奖励类、现金奖励类游戏。
1.6.3 色情类、血腥暴力类、涉及宗教、民族仇恨的游戏。
1.6.4 二次创作的同人游戏。
1.6.5 不具备游戏玩法与属性的应用软件。
1.6.6 违反国家法律法规的游戏。
# 2. 基础信息
# 2.1 厂商名
2.1.1 厂商名称仅限使用汉字、数字、字母，不得使用特殊符号。
2.1.2 厂商名称不得使用占位文本、空格、乱码等无关字符。
2.1.3 厂商名不得使用游戏名或个人姓名命名。
2.1.4 厂商名不得使用多个合并或并列厂商名。
# 2.2 游戏类型、兼容性
2.2.1 游戏类型需根据实际情况填写，不得选择与实际功能不符的分类。
2.2.2 游戏兼容性需根据实际情况选择，不得随意填写。
# 3. 物料审核
# 3.1 基本规范
3.1.1 文案、图片及视频不得含有违反平台收录标准的内容。
3.1.2 文案、图片及视频不得含有与游戏内容无关的素材。
3.1.3 文案、图片及视频不得含有侵权内容。
3.1.4 文案、图片及视频不得含有游戏商店评分等数据信息。
3.1.5 文案、图片及视频不得添加强制引导信息。
3.1.6 文案、图片及视频不得涉及游戏评价内容。
3.1.7 文案、图片及视频不得添加引导至其他网站的信息。
3.1.8 文案、图片及视频不得涉及微信号、QQ号等信息、链接、二维码、第三方账户信息等内容
3.1.9 图片及视频素材必须保证清晰，不得出现模糊、拉伸、压缩等情况。
3.1.10 图片及视频如需遮挡裸露角色敏感部位，需添加衣物，不得使用"圣光"、"暗幕"等。
3.1.11 游戏若需上架中国大陆地区，需提供简体中文版文案与物料。
# 3.2 ICON 图标
3.2.1 ICON 图标不得添加误导用户或违反相关规定的素材或角标。
3.2.2 ICON 图标必须符合游戏内容设定。
3.2.3 ICON 图标不得包含违法、色情低俗等非法字符和图案。
3.2.4 ICON 图标需清晰可辨，核心图形或LOGO需完整展示，避免模糊、拉伸、压缩等问题。
3.2.5 ICON 图标不允许出现空白或占位内容，必须能直观表达游戏的主题或特色。
3.2.6 ICON 图标需保证边缘完整，避免出现圆角或不规则切割。
3.2.7 ICON 图标禁止使用涉嫌侵权的素材，包括但不限于他人商标、LOGO、品牌词汇或特定设计风格。
3.2.8 ICON 图标中不得出现实物奖励、现金、代币等与实物有关的文字或图案。
3.2.9 ICON 图标中不得添加“NEW”、“HOT”、“红点”等角标，以免误导用户。
3.2.10 ICON 图标中不得包含测试数据、注销信息或调试信息。
3.2.11 禁止使用与游戏内容无关的特殊符号或无意义的文字、图案。
3.2.12 禁止使用与游戏无直接关联的热门词汇，例如“极速版”、“送百抽”等。
# 3.3 详情页截图
3.3.1 截图需与游戏内容一致，不得添加广告或误导信息。
3.3.2 禁止出现手机UI或重复单一截图
3.3.3 截图的内容需与游戏内容密切相关，真实反映游戏的核心玩法、功能和特色。
3.3.4 禁止侵权内容，包括但不限于未经授权的第三方商标、LOGO、版权内容或其他知识产权素材。
3.3.5 禁止在截图中添加虚假的下载按钮、分享按钮或其他模拟交互元素。
3.3.6 禁止添加误导性的标签或信息，如“独家上线”、“最高分”等未经验证的标签。
3.3.7 禁止在截图中添加水印、时间戳或其他非游戏内容的标记。
3.3.8 所有截图需保持正向，不得使用翻转、颠倒或旋转的图片素材。
3.3.9 详情页截图需和游戏实际内容一致，不得使用非该游戏内容的素材进行宣传推广。
# 3.4 宣传图​
3.4.1 宣传图需含有游戏名，且请勿出现游戏名以外的文字。
3.4.2 宣传图不得直接使用以未经排版的游戏截图。
3.4.3 宣传图不得使用多图拼接、平铺的素材。
3.4.4 宣传图不得出现游戏 ICON 图标素材。
3.4.5 宣传图不得添加误导信息，如虚假下载按钮。
3.4.6 宣传图除了以真人为卖点的游戏外，不得出现真人素材。
3.4.7 宣传图不得出现实物手机
3.4.8 禁止在宣传图中添加与游戏无关的文字、图案或信息，如广告、联系方式等。
# 3.5 简介及开发者的话
3.5.1 简介用以介绍该游戏玩法、特色，请勿添加无关广告信息。
3.5.2 简介与开发者的话不得违反基本法律法规，需符合基本要求。
3.5.3 简介与开发者的话不得含有违反平台收录标准的内容。
3.5.4 简介与开发者的话不得涉及游戏评价内容，包括邀请评价、引导好评等。
3.5.5 简介与开发者的话不得含有引战、蹭热度等信息。
3.5.6 简介与开发者的话不得含有引流信息。
3.5.7 简介与开发者的话不得包含兑换码（包括通码）、用户交流群、除 Steam 平台和 TapTap 详情页链接之外的外部链接。
3.5.8 简介内容不得可与开发者的话内容高度相似。
# 3.6 游戏标题
3.6.1 游戏标题用以填写游戏名，需与游戏资质对应，不得添加热门搜索词类副名称。
3.6.2 游戏标题中不得添加违反平台规定的信息。
3.6.3 游戏标题中不得添加误导用户、与游戏内容无关的信息。例如：极速版、重制版、送百抽。
3.6.4 游戏安装到手机上显示的 App 名称需与游戏详情页展示的游戏标题一致。
3.6.5 游戏标题中不得含有​除 ​​：，？！~ - · 外的特殊符号。
3.6.6 游戏标题不能使用无实质意义的字母、符号。
3.6.7 游戏标题不能使用“最高级”，“最好玩”等广告法禁止的相关词语。
3.6.8 游戏标题需与软著、版号保持完全一致，如软著与版号名称包含特殊符号，可在名称中省略。
3.6.9 游戏标题不得添加诱导消费和恶意竞争等相关词汇。
# 3.7 宣传视频、游戏实机录屏
3.7.1 视频内不得包含其他平台、剪辑软件的品牌水印。
3.7.2 视频内不得包含手机UI。包括模拟手机画中画，及手机状态栏、消息提醒、弹窗等手机UI。
3.7.3 视频内不得涉及表情包元素。
3.7.4 视频内容严禁包括含有色情、赌博等相关违规违法内容。
3.7.4 游戏实机录频规范可见游戏物料要求 (opens new window) 。
# 3.8 用户交流群
3.8.1 用户交流群名称需与游戏或官方匹配。
3.8.2 用户交流群名称不得带有引流信息。
3.8.3 用户交流群名称不得带有其他渠道或平台标识。
3.8.4 用户交流群号码不得填写多个号码。
3.8.5 用户交流群链接格式为纯链接，请勿添加其他文字或符号。

# 4. 商店配置
# 4.1 游戏状态
4.1.1 游戏状态请根据实际情况填写。
4.1.2 游戏未上线时，前台默认为「关注」。
4.1.3 未配置状态地区，游戏状态与「默认」保持一致。
# 4.2 官网链接
需填写游戏官方网站链接，不可填写第三方网站链接。
# 5. 安装包文件
# 5.1 包名
5.1.1 包名不得含有任何渠道相关标识。
5.1.2 包名须与官方包名保持一致。
5.1.3 请勿使用打包工具默认包名。
5.1.4 包名作为游戏唯一标识，请确保唯一性。
5.1.5 包名将用于接入 TapTap 开放平台的游戏服务，提示用户更新等，请确保 apk 包名资料与后台上传 apk 的实际包名一致
# 5.2 包体
5.2.1 小游戏包体为通过 TapTap 打包工具 打包出的指定 zip 文件。
5.2.2 为保障玩家体验，小游戏包体大小限制为 20MB 以下
5.2.3 上传包体后，程序将会自动读取该包体在打包工具中引用的小游戏库版本。
5.2.4 请确保上传包体内已正确接入 TapTap 登录 ，以防 TapTap 用户无法正常游玩。
# 5.3 版本号（ Version Code ）
5.2.1 游戏版本号不得为 0。
5.2.2 新提交安装包版本号不得低于当前版本号。
# 6. 资质文件及授权
# 6.1 游戏资质
6.1.1 上传游戏的公司如与软著或版号的公司主体为子母公司、分公司，请提交真实有效的证明。
6.1.2 上传游戏的公司如与软著或版号的公司存在授权关系，请提交完整、真实、可追溯的授权链证明。
6.1.3 上传游戏的公司如有软著或版号中的著作人、运营单位发生变更，请提交真实有效的证明。
6.1.4 如果存在授权关系，必须提供独家授权书文件。
# 6.2 运营和 IP 授权
6.2.1 游戏内容为运营代理，请提交完整、真实、可追溯的独家授权链证明。
6.2.2 游戏素材、剧情、音乐等内容涉及相关 IP ，需提交完整、真实、可追溯的授权链证明。
6.2.3 IP 权利人若为上传游戏的公司所有，需提交真实有效的证明。
6.2.4 IP 授权范围必须与上传游戏的内容吻合，且真实有效。
6.2.5 授权书格式必须为 JPG 或 PNG，每张图片大小不超过 2M，最多可上传 10 张。
# 6.3 素材授权
6.3.1 游戏素材不得使用版权敏感内容，包括但不限于网络素材、同人素材、其他游戏内素材。
6.3.2 游戏素材若有真人形象，需提交肖像使用授权书。
6.3.3 游戏素材若为原创素材，需提交真实有效的证明。
6.3.4 游戏使用素材若为购买的商业素材，需提交素材购买页面和订单证明。
# 6.4 版号
6.4.1 开发者需提供网络游戏出版物号（ISBN）以及核发单扫描件（ 必须为 JPG 或 PNG 格式 ），如果提交游戏的厂商非该版号运营单位，需提供相应版号授权，请务必保证授权链独家且完整。
6.4.2 如版号有更名、转移主体等历史，请务必提交完整的扫描件材料（ 拼接为同一张，必须为 JPG 或 PNG 格式 ）。
特别注意
ISBN 号格式必须为 999-9-9999-9999-1
如版号有更名、转移主体等历史，请务必提交完整的扫描件材料
根据国家有关规定，未经国家新闻出版广电总局批准的移动游戏，不得上线运营，即没有版号的游戏不得有任何形式的内购计费内容
如果游戏在大陆地区开放预约及信息展示，则暂不需要版号信息
如果游戏需要在大陆地区开放下载，请确保资质齐全，如果涉及授权，请提供独代授权
# 6.5 软著
6.5.1 开发者需提供权利获取方式为「原始取得」的软件著作权登记号以及登记证书扫描件（ 必须为 JPG 或 PNG 格式 ），如果提交游戏的厂商非该软著著作权人或权利获取方式为「受让取得」的，需提供相应软著授权，请务必保证授权链独家且完整。
6.5.2 如软著有更名、转移主体等历史，请务必提交完整的扫描件材料（ 拼接为同一张，必须为 JPG 或 PNG 格式 ）。
# 6.6 APP的 ICP 核准
开发者需要提供 APP 的ICP 核准信息，包括备案号和备案主办单位等信息，以确保应用的合法性和合规性，符合国家互联网信息管理的要求。
# 7. 政策相关
# 7.1 实名认证与防沉迷
7.1.1 实名认证和防沉迷所提交的信息必须真实有效。
7.1.2 实名认证和防沉迷的视频需符合 TapTap 实名认证和防沉迷说明中的填写要求。
# 8. 数据安全与隐私保护
# 8.1 用户授权与数据收集
​明示同意原则​：
在首次收集用户数据前，必须通过弹窗明确告知用户数据用途（如设备信息用于优化游戏性能），并提供「同意/不同意」选项，禁止默认勾选。
​最小化数据采集​：
仅收集必要的基础数据（如设备型号、游戏ID），禁止强制索要姓名、手机号、地址等敏感信息。
​拒绝授权处理​：
若用户拒绝授权，需立即清除已获取的数据，禁止后续功能依赖该权限。
# 8.2 数据使用与存储规范
​禁止数据滥用​：
不得将用户信息用于广告投放、信用评估等未经授权的场景。技术实现上，对手机号、邮箱等敏感信息进行脱敏处理（如显示为「138****1234」）。
​数据删除义务​：
小游戏服务提供者应该删除接收的所有关于该用户的数据，除非依据法律、法规，小游戏服务提供者有义务保留这些数据。
​数据安全防护​：
传输加密：所有用户数据必须通过 HTTPS 协议传输，禁止明文存储密码等敏感信息。使用工具（如 SSL Labs）验证证书有效性。
第三方合作限制：若接入广告、支付等第三方SDK，需在隐私协议中列明SDK名称及数据用途，并签订《数据保密协议》。禁止共享用户数据给未授权的第三方。
版号与数据安全联动：需提交《数据安全承诺书》，声明「未向第三方共享用户数据」（适用于含内购功能的游戏）。
# 8.3 地理位置管理
​使用场景限制​：
仅允许在「AR导航」「本地活动」等核心功能中使用位置数据，禁止在签到、任务系统中强制开启。
​权限控制​：
提供「仅在使用时获取位置」「关闭所有位置权限」两种选项，禁止默认开启高精度定位。
