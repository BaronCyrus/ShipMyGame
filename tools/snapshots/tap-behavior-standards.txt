# 小游戏行为规范
# 第一章 总则
目的
为维护 TapTap 平台健康生态，保障用户合法权益，规范开发者行为，根据《中华人民共和国网络安全法》《未成年人保护法》《网络游戏管理暂行办法》《关于防止未成年人沉迷网络游戏的通知》等法律法规及政策要求，制定本规范。
适用范围
本规范适用于所有在 TapTap 平台上线及运营的小游戏（含H5、轻量级应用等），开发者须严格遵守并配合平台审核与监管。
# 第二章 内容安全规范
# 一、小游戏本体内容安全规范
禁止性内容范围
小游戏本体（含文字、图像、音频、视频等）不得含有以下内容：
​违法违禁内容​：
违反宪法基本原则或损害国家尊严（如篡改国旗、国徽）；
宣扬恐怖主义、极端宗教、民族仇恨或分裂国家（如地图缺失领土）；
传播邪教、非法组织标识或煽动非法集会。
​低俗不良内容​：
直接或隐晦展示性行为、性器官、性暗示动作（如裸露敏感部位、模拟性交姿势）；
渲染血腥暴力（如断肢、内脏暴露、虐待动物）、毒品制作或吸食过程；
宣扬自杀、自残或美化犯罪手法（如详细描述抢劫、诈骗步骤）。
​价值观导向问题​：
歪曲历史人物或事件（如将侵略战争描述为“正义行动”）；
宣扬封建迷信（如占卜决定角色生死）、宿命论或性别歧视；
鼓励攀比炫富（如设置“充值排行榜”并公示用户金额）。
未成年人保护要求
​适龄提示​：
需在游戏启动页、应用商店页显著位置标注适龄标识（如“8+”“12+”“16+”），标识标准参考《网络游戏适龄提示规范》；
16+以上游戏不得向未实名认证或未成年人账号开放。
​内容过滤​：
角色对话、任务描述中不得出现“杀人”“色诱”“吸毒”等诱导性词汇（需替换为“击败”“吸引”“不良物品”等中性词）。
# 二、用户生成内容（UGC）发布规范
用户内容管控范围
开发者需对游戏内用户发布的以下内容进行实时监控与过滤：
​互动内容​：聊天、评论、昵称、签名、公会宣言等；
​创作内容​：用户上传的图片、视频、自定义角色外观、地图MOD等。
违规UGC类型
​违法信息​：发布违禁商品广告（如代练、外挂、色情服务）、赌博链接或政治敏感言论；
​人身攻击​：辱骂、恐吓、人肉搜索其他用户（如公开他人电话号码）；
​低俗内容​：上传色情头像、使用隐晦色情符号（如“约*”“+V看片”）；
​虚假信息​：传播游戏漏洞谣言、伪造官方活动骗取用户数据。
开发者管理义务
需在游戏内设置“敏感词库“系统，屏蔽违规内容；
用户举报的违规内容需在​24小时内删除​，并对发布者实施禁言、封号等处罚；
# 三、知识产权与内容侵权规范
侵权内容定义
​著作权侵权​：未获授权使用他人美术素材、音乐、代码、剧情文本（如抄袭知名游戏角色形象）；
​商标侵权​：擅自使用他人注册商标（如“王者荣耀”“原神”作为游戏名称或宣传语）；
​肖像权侵权​：未获授权使用真人肖像（如明星照片作为NPC形象）。
原创性证明要求
游戏上线前需提交核心素材（如角色原画、背景音乐）的原创声明或授权协议；
使用开源素材需注明来源并遵守对应许可证条款（如MIT、GPL协议）。
# 四、违规行为与处罚对照表
违规类型 具体行为示例 处罚等级 整改要求
违法违禁内容 游戏内含“港独”标语 特别严重违规 立即下架，报网信部门处理
低俗内容 角色服装透明可见内衣 严重违规 删除素材，限制搜索能力，限制时小游戏无法被用户搜索到
UGC人身攻击 用户评论出现“XX玩家是骗子，手机号138XXXX” 一般违规 删除评论，禁言发布者30天
著作权侵权 盗用《崩坏3》角色模型 严重违规 下架游戏，赔偿权利人损失
未落实适龄提示 未标注“16+”但含暴力战斗画面 轻度违规 24小时内补充标识
# 五、处罚执行与申诉
处罚流程
平台通过站内信向开发者发送《违规通知单》；
开发者需在7日内完成整改并提交证据，否则升级处罚等级。
从轻处理情形
首次违规且未造成传播；
主动配合删除侵权内容并公开道歉的，处罚降一档执行。
申诉材料
内容侵权争议：需提供原创证明、授权书或“避风港原则”适用证据（如UGC侵权时已履行删除义务）；
政治敏感内容误判：需提交内容解读说明及第三方审核意见。
# 六、合规建议
​内容自审工具​：
定期更新敏感词库（参考国家公布的《互联网敏感词清单》）。
​版权规避设计​：
避免使用知名IP元素，原创角色设计可申请外观专利；
剧情文本使用查重工具（如Copyscape）确保无抄袭。
附：相关法律依据
《中华人民共和国著作权法》第二十四条（合理使用范围）；
《网络音视频信息服务管理规定》第十条（UGC内容审核义务）；
《关于进一步压实网站平台信息内容管理主体责任的意见》（网信办，2021年）。
# 第三章 用户隐私与数据安全
# 一、数据收集与使用规范
最小必要原则
​允许收集的数据类型​：
账号基础信息：昵称、头像（默认提供系统随机头像选项）；
设备标识符：仅限匿名化设备ID（如Android ID、iOS IDFV），禁止收集IMEI、MAC地址；
游戏行为数据：关卡进度、成就、虚拟道具持有情况。
​禁止收集的数据类型​：
生物识别信息（如人脸、指纹）、声纹、健康数据；
通讯录、短信、通话记录、精确地理位置（除非游戏核心功能必需，如LBS游戏需单独弹窗授权）。
授权与告知义务
​隐私政策要求​：
需在游戏启动页提供《隐私政策》全文链接，链接按钮尺寸≥40×40像素，且不得默认勾选同意；
隐私政策需分章节说明数据收集目的（如“为提供排行榜功能，需获取您的游戏分数”）。
​动态授权​：
敏感权限（如摄像头、麦克风）需在具体使用场景中动态申请（如语音聊天前申请麦克风权限）；
用户拒绝授权后，不得限制基础游戏功能（如拒绝地理位置权限后仍可正常游玩非LBS模式）。
# 二、数据存储与传输安全
存储要求
用户数据需在中国境内服务器存储，跨境传输需通过国家网信部门安全评估；
敏感信息（如实名认证身份证号）需加密存储（AES-256及以上标准），且与可识别身份信息隔离存储。
传输加密
所有网络通信需使用HTTPS协议，禁用HTTP明文传输；
用户密码需加盐哈希处理（如bcrypt算法），禁止明文传输或存储。
留存期限
用户注销账号后，数据删除周期≤30天（日志类数据可匿名化保留6个月）；
未成年人数据在用户年满18周岁后自动触发匿名化处理。
# 三、用户权利保障机制
用户行权入口
需在游戏设置页提供以下功能：
​账号注销​：永久删除账号且不可恢复（需二次身份验证）。
响应时效
数据查询、删除请求需在15日内处理完毕；
账号注销需在7日内完成数据清理并邮件通知用户。
# 五、第三方服务与数据共享限制
SDK管理
使用第三方SDK（如广告、支付、社交登录）需向平台报备，并公示SDK名称、功能及收集数据类型；
禁止集成未经安全认证的SDK（如违规获取剪切板内容）。
数据共享合规
向第三方共享数据需在隐私政策中逐项列明（如“向支付宝共享订单号用于支付验证”）；
数据接收方需签署《数据安全承诺书》，且共享范围不得超出用户授权目的。
# 六、安全事件应急与处罚
数据泄露响应
发生数据泄露事件后，需在72小时内向平台及属地网信部门报告，并向受影响用户推送通知；
提供至少6个月的免费身份监控服务（如检测手机号是否被恶意注册）。
违规行为与处罚对照表
违规类型 具体行为示例 处罚等级 整改要求
超范围收集数据 收集用户通讯录用于“好友推荐”功能 严重违规 删除数据、关闭功能并重新设计
未加密存储密码 用户密码明文存储于数据库 特别严重违规 一经发现将根据违规程度对该小游戏限制分享、被搜索等其他能力直至封禁处理
未提供注销入口 游戏内无账号注销选项 一般违规 7日内上线注销功能
违规共享未成年人数据 向广告商提供14岁以下用户游戏时长数据 特别严重违规 下架游戏，移交司法机关处理
# 七、合规工具与技术支持
加密与匿名化建议
敏感数据加密推荐方案：
字段级加密：使用AWS KMS或阿里云KMS托管密钥；
匿名化处理：对用户ID进行哈希脱敏（如“用户123”转为“a1b2c3”）。
附：法律依据与标准
《中华人民共和国个人信息保护法》第13条（合法性基础）、第30条（未成年人信息保护）；
《信息安全技术 个人信息安全规范》（GB/T 35273-2020）第6.1条（数据最小化）；
《儿童个人信息网络保护规定》（国家网信办，2019年）第9条（监护人同意机制）。
# 第四章 防沉迷与付费管理
防沉迷系统
所有小游戏需接入 TapTap 平台统一实名认证系统，未实名用户禁止登录。
未成年人游戏时长限制：
法定节假日每日累计≤3小时，其他时间每日≤1.5小时；
每日22:00至次日8:00禁止登录。
付费规范
不得以“概率抽取”形式诱导未成年人充值，需明确公示抽取概率及规则。
单次充值金额不得超过法定限额（如单次≤50元，月累计≤200元）。
# 第五章 运营行为规范
# 一、广告与推广行为细则
广告展示要求
位置与尺寸
Banner广告（横幅广告）：
必须固定在游戏界面非核心操作区域（如顶部或底部边缘），​禁止遮挡游戏按钮、角色血条、任务提示等关键交互区域​；
单条Banner广告高度不得超过屏幕高度的10%，且需提供用户可随时关闭的明显按钮（如“×”标识）。
插屏广告（全屏/半屏弹窗）：
仅允许在游戏自然断点（如关卡结束、角色死亡复活前）触发，​禁止在战斗过程、任务对话中强制弹出​；
激励广告（用户主动触发）：
不得以虚假奖励诱导点击（如“100%必得道具”需与实际概率一致）；
广告播放期间需允许用户随时关闭，关闭后仍可正常返回游戏界面。
频率限制
非激励类广告（Banner、插屏）：
用户单次游戏会话（从启动到退出）中，广告展示总时长不得超过游戏时长的20%；
广告内容合规
禁止推广以下内容：
虚假宣传（如“点击即领100元红包”但无实际福利）；
低俗擦边（如性暗示、不当肢体暴露）；
强制跳转至外部应用商店或自动下载。
# 二、社区互动管理细则
社交功能设计要求
聊天系统：
需默认开启敏感词过滤（涵盖政治、色情、暴力等关键词）。
禁止私聊功能向未实名认证用户开放。
评论与排行榜：
游戏内排行榜需标注“仅显示昵称”，禁止公开用户真实姓名、手机号等隐私信息；
用户评论若被举报且核实违规，需在24小时内删除并禁言违规账号。
用户举报与反馈
针对恶意刷榜、虚假好评等行为，平台有权清除异常数据并降低游戏搜索权重。
# 三、游戏公平性保障细则
虚拟道具与付费规则
概率型道具（如抽卡、盲盒）：
需在道具详情页公示概率分布（精确到小数点后两位），且实际概率与公示值偏差不得超过±1%；
禁止设置“保底机制未触发时概率归零”等隐性规则。
付费礼包与订阅：
连续订阅服务需在扣费前3天推送提醒，并提供便捷退订入口；
礼包宣传语中不得使用“史上最低”“绝版限定”等无法证实的描述。
# 四、违规行为示例与处罚关联
违规类型 具体行为示例 对应处罚等级
广告违规 Banner广告遮挡“开始游戏”按钮 轻度违规（限期整改）

# 五、合规建议与示例
Banner广告合规示例

❌ 错误：广告覆盖角色技能按键区域，关闭按钮模糊不清。

✅ 正确：“观看完整广告视频，有30%概率获得10枚金币”；
❌ 错误：“点击立刻领取传说武器！（实际为随机碎片）”。

# 第六章 违规处理
# 一、违规行为定义与分级
平台根据违规行为的情节严重性、社会危害性及主观恶意程度，将违规行为分为以下四类：
轻度违规
轻微违反平台规则但未造成实质性损害的行为，例如：
未显著标注适龄提示或未按要求标注；
广告弹窗频率过高但未强制跳转；
非恶意代码漏洞导致用户体验受损。
一般违规
违反平台核心规则或对用户权益造成一定影响的行为，例如：
未接入实名认证系统或防沉迷系统；
未经用户授权收集非必要个人信息；
付费规则不透明（如未公示抽卡概率）。
严重违规
直接危害用户权益、破坏平台生态或违反法律法规的行为，例如：
传播低俗、暴力、血腥内容；
强制获取用户隐私权限（如通讯录、相册）；
利用外挂或漏洞非法牟利。
特别严重违规
涉及违法犯罪或造成重大社会负面影响的行为，例如：
宣扬恐怖主义、分裂国家等违法内容；
恶意诱导未成年人高额充值；
窃取、贩卖用户数据或实施网络攻击。
# 二、处罚方式
平台将根据违规行为等级采取以下处罚措施（可叠加执行）：
违规等级 处罚措施
轻度违规 * 书面警告并限期3日内整改。
一般违规 * 暂停游戏新用户注册或部分功能（如付费、社交）7-14日* 限制游戏推荐流量或榜单曝光。
严重违规 * 全平台下架游戏并冻结开发者账户；* 限制支付能力，限制时小游戏无法使用支付功能。* 禁止开发者1年内提交新游戏。
特别严重违规 * 永久封禁开发者账号及关联主体；* 向公安机关或监管部门报备；* 追究民事或刑事责任。
​注​：
同一游戏累计3次轻度违规视为一般违规，累计2次一般违规视为严重违规。
因违规导致用户损失的，开发者需承担全额赔偿并公开致歉。
# 三、整改要求
整改流程
收到处罚通知后，开发者需在7个工作日内提交整改计划，包括：
违规原因分析；
具体整改措施及时间表；
预防再次违规的机制说明。
平台将在10个工作日内审核整改方案，通过后允许恢复运营。
审核标准
内容违规：需彻底删除违规素材并提交内容自查报告；
技术漏洞：需提供第三方安全机构出具的修复证明；
用户投诉：需与受影响用户达成和解并留存凭证。
恢复运营
整改通过后，平台将解除处罚并恢复游戏服务；
恢复后30日内，游戏将纳入重点监管名单，若再次违规直接升级处罚等级。
# 四、申诉机制
开发者对处罚有异议的，可在收到通知后7个工作日内提交申诉，需提供：
完整游戏内容及运营数据；
第三方检测报告或法律意见书（如涉及技术或法律争议）；
其他有利于证明无违规行为的证据。
平台将在10个工作日内完成复核并书面反馈结果，申诉期间处罚措施暂不执行。
# 五、附则
本规则中“违规收益”指通过违规行为直接或间接获得的收入（含虚拟道具交易、广告分成等）。
平台有权根据违规行为的社会影响调整处罚力度，重大违规案例将公示处理结果。
# 第七章 附则
本规范将根据法律法规及政策要求动态调整，开发者须及时关注更新内容。
