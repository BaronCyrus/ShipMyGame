# MCP 安装指南
装好 MCP 后，你可以在 Cursor 里用中文跟 AI 说话来管理你的 TapTap 小游戏——上传游戏、加排行榜、接广告、做联机，全程不用写代码、不用翻文档。
::: warning 适用范围
当前 MCP 仅支持 H5 小游戏。Unity 及其他引擎的 TapTap 小游戏的 MCP 支持正在开发中，敬请期待。
:::
# 你需要准备什么
准备项 说明
Cursor 编辑器 去 cursor.com (opens new window) 下载安装（或其他支持 MCP 的 AI 编辑器）
TapTap 开发者账号 去 TapTap 开发者中心 (opens new window) 注册
# 安装步骤
下载 AI_SETUP_GUIDE.md (opens new window)
把它丢进你的游戏项目文件夹
用 Cursor 打开项目
在对话框里说："读一下 AI_SETUP_GUIDE.md，帮我配置好 TapTap MCP"
AI 会自动安装配置，然后弹出二维码让你用 TapTap App 扫码登录
扫码授权后，告诉 AI "我已经授权了"
完成。接下来直接用中文说你想做什么。
# 你能做什么？
装好 MCP 后，直接用中文跟 AI 说话。不需要记任何命令。
# 游戏管理
帮我看看我有哪些应用
帮我创建一个新游戏
帮我更新游戏截图
我的游戏审核到哪了？
# 上传游戏
帮我把 dist 目录下的游戏上传到 TapTap
# 排行榜
帮我加一个排行榜，按分数从高到低，每周重置
排行榜怎么接入到代码里？
# 多人联机
我想做一个联机对战功能
联机的时候位置不同步怎么办？
# 分享 / 云存档 / 振动
帮我加一个分享功能
我想给游戏加云存档
怎么加振动效果？
# 遇到问题？
先问 AI。大多数问题 AI 都能帮你排查和解决。
MCP 连不上怎么办？
广告不显示怎么回事？
帮我重新登录
如果 AI 也解决不了，试试重启 Cursor 重新来过。
