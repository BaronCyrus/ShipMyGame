# IAA游戏
# 1. TapTap 小游戏的广告变现形式
普通小游戏开发者目前可以通过接入 Dirichlet (opens new window) （又名TapADN），快速实现广告变现。
接入Dirichlet后可以请求多个广告平台，采用 Bidding + Waterfall 的混合模式最大化广告收益。
目前已支持的广告平台有：穿山甲 (opens new window)，优量汇 (opens new window)；后续将会支持更多广告网络。
# 2. Dirichlet 的优势所在
# 高额的广告收入回报
0 分成，开发者可得到 100% 的现金分成比例；
聚合了市场上主流联盟广告平台的预算，帮助开发者提升广告变现效率，相较于大部分竞媒的 eCPM，TapADN 的 eCPM 相对较高；
# 高质量广告供给，对游戏留存更好
Dirichlet 严格筛选的游戏直投广告客户和素材，提供高品质的广告供给，不存在 p2p、贷款、交友等低俗广告，对游戏留存和用户体验更佳；
Tap 广告将自动安装权限完全交由开发者，Tap 不会主动开启自动安装，对玩家游戏体验和评分维护更好;
# 流量扶持助力游戏用户增长
为了扶持开发者，TapTap 侧会按比例对开发者给的流量做 Tap 平台曝光扶持（走聚合平台接入且以竞价形式露出无流量扶持）具体扶持策略如下：可折算为开发者每变现 1 块钱配套给到 4-6 个 TapTap 曝光（曝光位置为首页推荐）；Dirichlet 系统自动补量，「D+1结算」，即当日产生的收益，次日系统自动消耗补量，具体补量展现可在后台查看。
# 3. 如何接入广告变现功能
第一步 创建广告位：在Dirichlet广告平台 (opens new window)基于帮助文档 (opens new window) 创建 媒体 和 推广位，并获取推广位 ID（adUnitId）
第二步 接入广告 SDK：在小游戏代码中调用相应的广告 API
第三步 测试验证：在开发环境中测试广告展示效果，建议配置测试工具，保障测试广告位的展示效果
第四步 提交审核：在Dirichlet 提交正式广告位进行审核，审核通过后广告即可正常展示
查看详细的开发指引请前往：广告接入 (opens new window)
# 4. TapTap 对小游戏广告的要求
为向用户提供更优质的小游戏体验，TapTap 对小游戏内的广告样式和具体体验制定了审核规范。未达标的小游戏将无法通过审核，开发者可以按照指引整改后重新提审。
