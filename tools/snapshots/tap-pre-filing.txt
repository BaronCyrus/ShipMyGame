# 小游戏前置备案
小游戏前置备案是 TapTap 面向普通小游戏提供的一站式备案服务，整合了原有的小游戏备案与 ICP 核准流程。根据工信部管理规定，小游戏在上线前需完成该流程，方可满足上线前备案要求。
本文内容主要面向普通小游戏；创意工坊或 TapTap 制造游戏请以对应的实际要求为准。
# 1. 办理入口
请前往 TapTap 开发者中心，进入：
商店 -> 小游戏管理 -> 小游戏资质
在 小游戏前置备案 卡片中，点击 提交核准信息 进入办理流程。
# 2. 办理流程
小游戏前置备案共分为三个步骤：
填写核准资料
电子化核验
提交审核
建议在开始前准备好相关材料，并确认联系人信息、包体信息和上传文件内容准确无误，以减少反复修改和补充提交的情况。
# 3. 第一步：填写核准资料
进入办理页面后，首先需要完成核准资料填写。当前页面包含以下信息模块：
开发者认证
小游戏包体
软件著作权人
游戏内容介绍说明
小游戏负责人基本情况
身份信息核验
补充材料
请根据页面提示依次填写或上传相关资料，并确认信息真实、完整、有效。
# 3.1 开发者认证
系统会展示当前开发者认证状态。请先确认开发者认证信息完整有效，再继续后续核准流程。
# 3.2 小游戏包体
请选择用于本次前置备案的小游戏包体。
建议确认所选包体信息与实际上线内容一致，避免因包体与实际内容差异过大影响审核。
# 3.3 软件著作权人
请按页面要求填写软件著作权人名称，并确保与相关权属材料保持一致。
# 3.4 游戏内容介绍说明
请上传游戏内容介绍说明文件，并尽可能清晰说明游戏功能、主要内容分类和核心玩法。
如您的游戏已拥有版号，请先上传版号，且无需再上传游戏内容介绍说明。
# 3.5 小游戏负责人基本情况
请先确认小游戏负责人的填写身份符合要求：
开发者认证主体为个人身份时，小游戏负责人必须为开发者认证主体本人。
开发者认证主体为企业身份时，小游戏负责人可授权第三人担任。
请按要求填写小游戏负责人姓名、证件类型、证件号码、证件有效期、手机号、电子邮箱和应急联系电话等信息。
请确保负责人信息真实有效，并保持手机畅通，以便后续接收核验短信。
# 3.6 身份信息核验
请按页面要求上传小游戏运营负责人身份材料及相关主体证明材料。
上传材料时，请确保图片或文件内容清晰、完整、在有效期内，并与填写信息保持一致。
# 3.7 补充材料
请根据页面提示判断是否需要补充上传相关材料，并根据提供的模版要求提交例如：
小游戏负责人授权书（非必填）：系统会根据主体信息、负责人信息等自动判断是否需要补充。
不涉及前置审批承诺书（非必填）：系统会根据主体信息、地区信息及申报内容自动判断是否需要补充。
# 3.8 进入下一步
所有资料填写完成后，点击页面右上角的 下一步，进入电子化核验。
# 4. 第二步：电子化核验
进入电子化核验页面后，请先点击 生成核验码。
生成核验码后，请由运营负责人使用微信或支付宝扫描二维码完成核验。页面提示该核验预计耗时约 10 分钟。
核验过程中，请关注页面中的 核验状态。核验通过后，即可进入下一步提交审核。
# 5. 第三步：提交审核
电子化核验完成后，点击页面右上角的 提交核准信息，正式提交小游戏前置备案申请。
提交完成后，系统将进入审核阶段。
# 6. 审核中
提交成功后，页面会进入审核中状态。
请注意以下事项：
相关核准材料提交后，如无问题，全程预计 20 个工作日内完成相关核准。
小游戏前置备案初审通过后（初审预计耗时12～16工作日），工信部会向小游戏负责人发送短信进行核验。
请在收到短信后 24 小时内根据提示完成认证，否则申请将被自动退回，需重新提交核准。
审核期间，请保持负责人联系方式畅通。
# 7. 审核通过后
审核通过后，页面将展示核准结果信息，表示小游戏前置备案已完成。
开发者可点击 查看核准信息 查看以下内容：
服务核准号
主办单位名称
服务名称
审核通过后，开发者也可以重新进入 商店 -> 小游戏管理 -> 小游戏资质 页面，点击 查看核准信息 查看备案信息。
至此，小游戏前置备案流程已全部完成。接下来可继续进行版本提审、物料完善及其他上线准备工作。
