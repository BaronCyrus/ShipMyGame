# 收款：Dirichlet（TapADN）广告收入

Unity 导出的 Tap 小游戏只能接 Dirichlet 的广告，见 [capabilities.md](capabilities.md) 第 5 节。个人能不能把广告收入拿到手，**还没有确认**。接广告前，先把下面这些讲给用户。

## 1. 协议怎么写

依据：Dirichlet 媒体平台的《服务协议》，2026-11-03 读取。它不是 TapTap 的官方文档，也没有单独的网址：在 https://ssp.dirichlet.cn/ 登录框下方点《服务协议》打开。

- 签约方可以是自然人。在平台填的银行账号要和认证的主体名称一致（第 2.2 条）。
- 每个自然月结算一次。个人开发者一个周期内累计未结算的金额不足 1000 元（含税）时，平台可以暂不结算；企业是 5000 元（第 4.2 条）。
- 每月 20 日前确认上个月的数据，打印结算单并签字（企业盖章），连同等额的**增值税专用发票**（开票类目：广告发布费）一起寄给平台（第 4.3.1 条）。
- 平台收到合格的专用发票和确认过的结算单后，30 个工作日内汇到指定的银行账户（第 4.3.2 条）。
- 展示、点击和结算金额以平台统计为准，平台认定为无效流量的金额会被扣掉（第 4.1 条）。

## 2. 没确认的一点：个人怎么出专用发票

个人自己开不了增值税专用发票。能不能到税务局代开、Dirichlet 认不认代开的专票，协议没写，本仓库也没查到官方说法。

所以接广告前：

1. 请**用户**问 Dirichlet 客服：个人开发者怎么提供协议要求的专用发票。
2. 把答复记进进度档案。能走通的话，按仓库 README 的「反馈」一节告诉维护者，更新本节。
3. 走不通又想靠广告赚钱，就要换成个体户或公司主体，TapTap 开发者也要用同一个主体，见 [onboarding.md](onboarding.md) 第 1 节「以后想做广告时」。

## 3. 容易看混的

- 零分成：TapTap 官方写开发者拿 100% 现金分成 [官方](https://developer.taptap.cn/minigameapidoc/quick-start/monetization/IAA-game/)。
- 同一页的「D+1 结算」说的是曝光扶持：当天的变现收益按比例折成 TapTap 首页推荐的曝光，第二天自动补量。它不是现金到账。
- 内购：个人做不了，要版号和企业财务认证，见 [capabilities.md](capabilities.md) 第 11 节。
