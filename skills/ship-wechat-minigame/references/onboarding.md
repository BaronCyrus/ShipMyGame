# 注册与账号初始化

每一步都标了谁来做：**你**是 agent，**用户**是游戏的主人。

## 1. 注册个人主体小游戏账号（用户做）

- 实测：用户本人注册，从打开注册页到进入后台约 20 分钟 `[实测]`。
- 注册过程没有留下截图，所以下面第 2～4 步按官方流程写 `[官方]`。
  - 来源：[注册流程](https://kf.qq.com/faq/170109iQBJ3Q170109JbQfiu.html)（腾讯客服，官方接入指南直接链接到这里）、[注册账号](https://developers.weixin.qq.com/minigame/introduction/guide/register.html)。

**开始前，你先告诉用户要准备什么**
- 一个邮箱。它不能注册过公众平台、开放平台或企业号，也不能绑定过个人微信。一个邮箱只能注册一个账号。
- 主体类型选「个人」。要求是 18 岁以上、有中国大陆居民身份信息的微信实名用户。
- 管理员本人的微信，用来扫码确认。
- 游戏名。要用纯中文，第 2 节解释原因。

**步骤**

1. **你**：在用户的 Chrome 里新开一个标签页，打开 `https://mp.weixin.qq.com/`。告诉用户点右上角的「立即注册」，账号类型选「小程序」。
2. **用户**：
   - 填邮箱和密码。
   - 到邮箱里取 6 位验证码，填回注册页激活。
   - 类目选「小游戏」。原文：「小游戏类目一旦设置成功，将不得修改为其他一级类目」。
3. **用户**：
   - 主体类型选「个人」，按页面填主体信息和管理员信息，用管理员微信扫码。
   - 原文：「确认主体信息不可变更」。
4. **你**：用户说注册好了之后，读后台首页，确认两件事 `[实测]`：
   - 左侧菜单里有「游戏能力地图」，说明一级类目已经是游戏。
   - 页面左下角显示了中文游戏名。

**不要从测试号起步。**
- 测试号的后台只有「开发者 ID」「服务器域名」「业务域名」三块，没有能力地图，也开不了快适配。
- 用测试号的 AppID 导出的 Unity 包，运行时报 `UnityManager is not a constructor` `[实测-失败]`。
- 所以，想在真机上跑 Unity 包，就得先有正式账号。不是等到上线前才需要注册。

## 2. 名称、简称、头像、介绍（你填，用户确认）

在「账号设置 → 基本设置」里改。规则和修改次数见 [listing.md](listing.md#名称简称头像介绍)。

要点：
- 游戏名用纯中文。名称里有英文或「软件」二字时，资质审核会要求软件著作权登记证书 `[官方]`（[资质审核-IAA](https://developers.weixin.qq.com/minigame/introduction/guide/zzsh-iaa.html)）。实测用纯中文名，全程没有被要求交软著 `[实测]`。
- 资质、小游戏备案提交以后，到小程序备案完成之前，名称和主体都不能改，否则两个备案都要重来 `[实测]`。这一点是后台流程指引页原文，另见 [小游戏备案](https://developers.weixin.qq.com/minigame/introduction/guide/nrjs.html)。

## 3. 类目（你操作，扫码由用户做）`[官方]`

来源：[类目设置](https://developers.weixin.qq.com/minigame/introduction/guide/type.html)。

1. 首页「小程序类目」→「去补充」→「添加类目」。
2. 管理员用微信扫码验证。这一步是本人事项。
3. 「服务类目」里选二级类目，保存后立即生效。

注意：
- **个人主体不能选「文化互动」「角色类」「牌类」。**
- 二级类目要和游戏实际内容一致，不一致的话提审时会被驳回。
- 二级类目在发布后就锁定了；文化互动选了以后也不能改。
- 三级类目可以在「资质管理」里随时改，但要重新过资质审核，并且发新版本才生效。
- 后台核对：服务类目显示的格式是「游戏 > 休闲游戏」（2026-11-02）。

## 4. 运营地区（你核对）

2026-11-02 在后台核对到：首页「小程序开发与发布流程」的「完善基础信息」里多了一项「运营地区」。页面说明原文：「选择小游戏的上架地区，进入对应的运营及开发环境」。「账号设置 → 基本设置」里显示的是「中国内地（大陆）地区」。

- 本 skill 只覆盖中国内地（大陆）地区，保持这个选项不动。
- 选其他地区会带来什么差别：**未确认**。

## 5. 开通快适配（你做，约 1 分钟）`[实测]`

Unity 导出的包要靠官方 Unity 插件运行，必须先在后台开通。

1. 左侧「功能」→「游戏能力地图」→ 顶部页签「研发能力」。
2. 点「生产提效包」卡片。它带「性能」「存储」两个标签，说明文字提到高性能模式、快适配。
3. 在列表里找到「快适配」，点右侧的「立即申请」。
   - 没有表单，页面顶部出现提示条，按钮变成灰色的「已开启」。
   - 实测从点击到开发者工具里插件能加载，不到 10 分钟，不需要等审核。

页面路径的其他写法：
- 官方 Unity 文档写的是「能力地图-生产提效包-快适配」（[来源](https://developers.weixin.qq.com/minigame/dev/guide/game-engine/unity-webgl-transform.html)）。
- SDK 生成的 `game.js` 报错提示里还是旧名字「开发提效包」。
- 以页面实际显示为准。

开发者工具提示「插件申请成功，待审核确认」或「插件未授权」时，原因也是没开快适配 `[官方]`（[Unity QA](https://developers.weixin.qq.com/minigame/dev/guide/game-engine/unity-webgl-transform/Design/DevelopmentQAList.html)）。

## 6. 读 AppID（你做）`[实测]`

位置：「管理 → 开发管理 → 开发设置」，顶部第一个页签「开发者ID」区域显示「AppID(小程序ID)」。

在这个页面执行下面的代码取值：

```js
document.body.innerText.match(/wx[0-9a-f]{16}/g)
```

把 AppID 写进两个地方：进度档案的「标识」一行，以及 `publish/wechat/build.json` 的 `appid`。

不需要 AppSecret：
- 开发者工具的预览、上传，用的是工具的登录态；miniprogram-ci 用的是上传密钥。
- 所以不要生成 AppSecret，也不要读出来或复述。

## 7. 安装微信开发者工具并登录 `[实测]`

1. 先告诉用户安装包的大小和位置，得到同意再装。
   - 实测 macOS arm64：Stable 版 dmg 约 243MB，装好后约 737MB。
   - 缓存和登录数据在 `~/Library/Application Support/微信开发者工具/`，用久了会变大。
2. 安装：
   - macOS：`brew install --cask wechatwebdevtools`，加 `--appdir=<目录>` 可以装到指定位置。
   - 其他系统：从[官方下载页](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)下载。
   - **要装稳定版 Stable Build，不要装「小游戏版 Minigame Build」** `[官方]`（[来源](https://developers.weixin.qq.com/minigame/dev/guide/game-engine/unity-webgl-transform/Design/Transform.html)）。
3. **用户**：第一次打开时，用手机微信扫码登录。登录态能保持很多天 `[实测]`。
4. 用 computer use 操作它时，应用的 bundle id 是 `com.github.Electron`，显示名是「微信开发者工具」 `[实测]`。

## 微信认证

- 实测：个人主体的微信认证 10-24 已完成，由用户本人办理，过程细节没有记录 `[实测]`。
- 下面的步骤按官方写 `[官方]`。来源：[微信认证](https://developers.weixin.qq.com/minigame/introduction/guide/wxrz.html)、[个人认证流程](https://kf.qq.com/faq/231114eyInYR23111463uqeM.html)、[认证特权](https://kf.qq.com/faq/170109quaQbu170109AJnArI.html)、[认证审核问题](https://kf.qq.com/faq/170109jQbAV3170109aQ3ERj.html)。

**入口**：左侧菜单「微信认证」，或者「设置 → 基本信息 → 微信认证 → 去认证」。

**步骤**（用户做；你打开页面，并用三五句话讲清协议要点）
1. 签署《微信公众平台认证服务协议》。
2. 填资料，完成主体验证。「职业认证」可以选择不申请。
3. 填名称。未发布的账号没有这一步。
4. 填发票。个人只能开电子发票，提交后不能修改。
5. 用微信支付付费。

**时长**：付费后 1～3 个工作日。

**费用**
- 官方页面没有写个人认证的金额，以支付页显示为准（**未确认**）。
- 原文：「无论认证成功或失败，都需要支付审核服务费」。

**为什么要做，以及什么时候做**
- 后台首页原文（已在后台核对）：「完成微信认证后，账号可获得"被搜索"和"被分享"能力。未完成微信认证不影响后续版本发布」。
- 但实测 10-24 的「小游戏备案&发布流程指引」页要求：先完成资质、小游戏备案**和微信认证**，才能开始小程序备案。
- 两个页面说法不同，以流程指引页为准：在 P4 就把认证办掉，否则会卡在小程序备案。

## 成员和体验成员

`[官方]`

来源：[协同工作和发布](https://developers.weixin.qq.com/miniprogram/dev/framework/quickstart/release.html)、[MP 用户权限管理](https://developers.weixin.qq.com/minigame/introduction/guide/permission.html)。

- 入口：「管理 → 成员管理」。
- 分两类：
  - 项目成员：运营者、开发者、数据分析者，可以登录后台；
  - 体验成员：只能打开体验版。
- 本次实测没有加过成员。测试全程由管理员本人扫开发版的预览码 `[实测]`。
- 需要别人帮忙测试时：
  - 在「成员管理 → 体验成员」里添加；
  - 或者用 `miniprogram-mp-ci` 批量添加。调用后要管理员在微信里确认，见 [automation.md](automation.md#体验成员)。
