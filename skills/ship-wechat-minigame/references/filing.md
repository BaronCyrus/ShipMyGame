# 资质、小游戏备案、小程序备案

不开通虚拟支付的游戏，官方叫 IAA 游戏。它在发布前必须走完这条链 `[官方]`（[IAA 游戏发布指引](https://developers.weixin.qq.com/minigame/introduction/guide/iaa.html)、[接入指南](https://developers.weixin.qq.com/minigame/introduction/guide/)）：

```
资质提交（情况二）─┐
                    ├─→ 小程序备案（ICP）─→ 拿到备案号 ─→ 审核通过的版本才能发布
小游戏备案 ────────┘        ↑
微信认证 ───────────────────┘   （流程指引页要求认证完成后才能开始小程序备案）
```

- 资质和小游戏备案可以同时提交，没有先后顺序（实测时流程指引页原文）。
- 版本审核可以和小程序备案并行 `[官方]`。实测时，「版本提审」的「前往提交」按钮在前面步骤没完成前是灰的，以后台按钮实际能不能点为准。
- 官方预估整个流程 13～37 个工作日 `[官方]`。

入口：「首页 → 小程序备案 → 小游戏备案&发布流程指引」。页面按顺序列出：资质提交、小游戏备案、小程序备案、版本提审，每项都有状态和预计用时 `[实测]`。

**锁名规则**（实测时流程指引页原文，另见[官方](https://developers.weixin.qq.com/minigame/introduction/guide/nrjs.html)）
- 小程序备案完成之前，不要改游戏名称、不要迁移主体，否则小游戏备案和小程序备案都要重新发起。
- 小游戏备案提交后，不论是审核中还是已通过，都不允许改名称或主体。

## 资质提交

**实测情况** `[实测]`
- 由用户本人提交，时间在 10-24 之前。
- 10-31 查看时已通过。
- 流程指引页对这一步的说明原文：提交材料，并在页面内选择「不同时申请支付」；预计约 1 个工作日。
- 提交过程没有记录，下面的字段按官方写 `[官方]`（[资质审核-IAA](https://developers.weixin.qq.com/minigame/introduction/guide/zzsh-iaa.html)）。

**入口**（任选一个）
- 「首页 → 小程序备案 → 小游戏备案&发布流程指引 → 资质提交」
- 「账号设置 → 游戏设置 → 资质与授权管理 → 资质管理 → 前往管理」

**步骤**
1. 游戏情况选「情况二：小游戏当前及未来均不需要开通虚拟支付」。需要虚拟支付的游戏选情况一，但个人主体不能开虚拟支付，开通条件原文是「主体类型为个体工商户或企业已认证小游戏」（[虚拟支付进件](https://developers.weixin.qq.com/minigame/introduction/commercialization/virtual-payment/)）。
2. 三级类目选和游戏内容一致的，支付资质选「不申请」。
3. 上传材料。原文：「切勿错位上传」。签字类材料由用户本人签。
4. 提交。审核中想修改时，在「资质管理」点「撤回审核」，再提交要重新排队。

**什么时候要交软件著作权登记证书**：只在以下情况要交——游戏名含英文或「软件」二字，或者涉及品牌、公众人物合作。

**常见驳回原因**
- 游戏名或签署主体前后不一致，例如材料里「个人」和「我司」混用。
- 签名不是本人姓名，或者用了艺术签、铅笔。
- 缺签署日期。

**时长**：官方 1～3 个自然日；流程指引页写约 1 个工作日。

## 小游戏备案

小游戏备案是 IAA 游戏的前置审批。已有版号的游戏不用做 `[官方]`（[小游戏备案](https://developers.weixin.qq.com/minigame/introduction/guide/nrjs.html)）。

**实测情况** `[实测]`
- 10-23 开始填表，10-24 提交。
- 10-31 查看时已过平台初审，状态是「主管部门审核中」。
- 「主管部门已通过」之后的环节还没有实测。

### 提交前准备

- 名称已定稿：一旦提交就锁定。
- 资质已提交：官方要求资质已提交或已通过。
- 适龄提示已提交：没设置会拖慢备案。
- 有一个能在手机上运行的预览版：主页显示中文游戏名，已关掉「优化建议」弹窗，入口都能用。
- 网络类型已经定好（单机或联网），见 [console.md](console.md#用户隐私保护指引)。

### 打开表单

- 入口：「首页 → 小程序备案 → 小游戏备案&发布流程指引」，点小游戏备案右侧的「前往提交」。
- 也可以从「账号设置 → 基本设置 → 小程序备案 → 去完善」进入。
- 表单网址见 [console.md](console.md) 的路径表。
- 顶部步骤条：①游戏类型及相关文件 → ②填写游戏内容 → ③信息预览。

### 第 1 步：游戏类型及相关文件（用户做）`[实测]`

1. 「游戏类型」：两个下拉框，实测选的是「休闲类」「益智」。第 2 步「玩法」栏会据此自动生成一句开头。
2. 「网络类型」：「单机」或「联网」。页面说明原文要点：
   - 单机是游戏自身功能不联网也能在本地运行，防沉迷、广告变现不算游戏自身功能。
   - 联网是游戏包含要联网才能运行的功能。
   - 这段说明容易让人以为单机游戏不用做小程序备案。但流程指引页和提审文档都把小程序备案列为发布前必须完成，所以**单机也要做小程序备案**。
3. 「请签署相关文件」：用户用手机微信扫码，签署三份文件：《著作权自我声明》《代备案授权书》《单机承诺函》。
   - 签署不收费，签好后系统会自动上传文件图片。
   - 重新扫码签署时，新签名覆盖旧签名。
4. 个人主体、纯中文名时，界面上不显示「营业执照」「计算机软件著作权登记证书」上传位，页面结构里有，但隐藏着。
5. 点「下一步」。

### 第 2 步：填写游戏内容（你做）`[实测]`

- 页面标题是「<类型> 必填内容」，分三块：场景、玩法、系统功能。
- 文字照 `templates/filing-content.md` 写。**先读代码核实**游戏里真实有哪些系统、规则和数字，再写。
  - 实测时，一个数量最初写错了，核对代码后才改正。

**场景**
- 「各主要场景描述」：要求至少 30 字，上限 800 字。
- 「相关截图」：至少 3 张。

**玩法**
- 「整体玩法设计」开头会自动生成一句「《<游戏名>》是一个休闲类小游戏，游戏的内容类型为益智。」，要改只能回第 1 步改类型。
- 下面的「具体玩法为：」输入框：要求至少 50 字，上限 800 字。
- 「相关截图」：至少 3 张。

**系统功能**
- 「系统N」下拉选项：货币系统、商城系统、兑换码系统、会员/VIP系统、道具系统、体力系统、排行榜系统、设置系统、自定义系统。
- **系统 1 默认是「货币系统」，游戏里没有货币就一定要改掉。**
- 选「自定义系统」后会出现名称框，输入后按回车确认。
- 每个系统：说明至少 30 字、上限 800 字，截图至少 1 张。用底部的「+ 新增系统」继续添加。
- 有激励视频的系统，要写清看广告能得到什么，并写明「没有任何游戏货币，也不能用现金购买」。

**选填内容**：游戏背景、扮演角色、NPC、主要情节、主要特点，默认折叠，可以不填。

**截图规则**
- 页面原文要点：JPG、JPEG 或 PNG，60KB～5MB；必须是微信游戏截图，截图里的小游戏名必须是当前小游戏名。
- 官方还要求截图的尺寸、版本保持一致。
- 截图清单和拍法见 [listing.md](listing.md#备案截图)。

**怎么填**
- 改文本框：取 `HTMLTextAreaElement.prototype` 原生的 `value` setter 赋值，再派发带 `bubbles: true, composed: true` 的 `input` 和 `change` 事件。
- 传截图：用本机中转法（[uploads.md](../../ship-my-game/references/uploads.md)），**一次只传一栏**，等缩略图出现再传下一栏。
  - 实测一个脚本连传 5 栏、间隔 2.5 秒时，有两栏被后传的覆盖了 `[实测-失败]`。
  - 上传框藏在 shadow root 里，要按旁边的标签文字（「相关截图」「系统1截图」…）确认是哪一栏。实测的顺序是：第 0、1 个是营业执照和软著（隐藏），第 2 个是场景，第 3 个是玩法，第 4～7 个是系统 1～4。
  - 用 `new File([blob], '<ASCII 文件名>.jpg', {type: 'image/jpeg'})` 生成文件，放进 `DataTransfer`，赋给 `input.files`，再派发带 `bubbles` 和 `composed` 的 `change` 事件。
  - 缩略图的 `img.src` 变成 `https://gamemp.weixin.qq.com/...` 开头，就说明已经传到微信服务器。
- 点「保存」，等页面出现「保存成功」。按坐标点有时看不到提示：改为在 shadow root 里找 `innerText === '保存'` 的按钮执行 `click()`，再轮询提示文字。
- 刷新后核对：文字长度都在。下面几栏的图片要滚动到可见位置才会加载，刚刷新时数到 0 张是正常的。

### 第 3 步：信息预览和提交（走提审闸门）`[实测]`

1. 把以下内容列给用户：游戏类型、网络类型、三段文字的要点、每栏截图的张数，以及「提交后不能改名、不能迁移主体」。
2. 用户说「提交」后，点「下一步 → 信息预览 → 提交」。实测是用户自己点的。

完成标准：流程指引页的小游戏备案显示「平台审核中」。

### 审核状态和时长

**状态流转** `[官方]`
- 平台审核中：还能在编辑页底部点「撤回」，改完再提交。
- 平台驳回：按驳回原因改了再提交。
- 主管部门审核中：**什么都不要动**，不改名称、不迁移主体。
- 主管部门已驳回：按原因改了再提交。
- 主管部门已通过：去做小程序备案。
- 信息更新：备案通过后，小程序信息和备案不一致时会出现，要按《小游戏备案信息更新指引》更新。

**时长**
- 平台初审 1～2 个工作日，主管部门 10～20 个工作日。修改或驳回后，从下一次提交重新计时 `[官方]`。
- 流程指引页写的是约 10 个工作日 `[实测]`。
- 有开发者在社区说主管部门那一步等了好几个月：只能当线索，按最坏情况告诉用户。

**常见驳回原因** `[官方]`
- 同名游戏已经获批：只能改名重提，新名字要和玩法相关。
- 提交后改过名或迁移过主体：要重走小游戏备案。
- 资质没提交或没通过、适龄提示没设置，会拖慢进度。

## 小程序备案（ICP）

**整体是 `[官方]`**，本仓库还没有走到。2026-11-02 后台显示「未备案」。来源：[小程序备案（接入指南）](https://developers.weixin.qq.com/minigame/introduction/guide/xcxba.html)、[备案操作指引](https://developers.weixin.qq.com/minigame/product/record/guidelines.html)、[短信核验](https://developers.weixin.qq.com/miniprogram/product/record/sms_verification.html)、[材料示例](https://developers.weixin.qq.com/miniprogram/product/record/record_material.html)。

**什么时候开始**
- 小游戏备案「主管部门已通过」，并且微信认证已完成。
- 实测时，流程指引页原文写的是「先完成以上2个步骤及微信认证」，按钮「开始备案」在这之前是灰的。

**入口**
- 「首页 → 小程序备案 → 小游戏备案&发布流程指引」的「开始备案」。
- 或者「账号设置 → 基本设置 → 小程序备案 → 去完善」。
- 情况选「情况二」（IAA 游戏），备案类型选「新增备案（首次备案）」。

**分工**

| 环节 | 内容 | 谁做 |
|---|---|---|
| 主体信息 | 证件类型选居民身份证，证件有效期要大于 1 个月；通信地址写实际地址；上传证件原件的彩色扫描件或照片，清晰完整 | 用户上传证件；地址你可以预填，由用户核对 |
| 主体负责人 | 手机号必须是本人使用的；应急联系人的手机号也必须是本人使用的，而且两人不能用同一个号码 | 用户 |
| 小程序信息 | 服务内容和前置审批：小游戏的前置审批，就是已通过的小游戏备案（推断） | 你预填，用户核对 |
| 小程序负责人 | 个人主体默认复用主体负责人。现场拍照做人脸核身：白色或浅色干净背景，不戴帽子、耳机、口罩，表情自然 | 用户 |
| 承诺书 | 阅读并确认《互联网信息服务承诺书》 | 你讲清要点，用户勾选 |

**提交后**
1. 平台初审：1～2 个工作日，期间保持电话畅通。
2. 工信部短信核验：
   - 初审通过后，负责人手机会收到 12381 发来的短信。
   - 要在 **24 小时内**登录 `https://beian.miit.gov.cn/` 完成核验。手机端和电脑端都可以。
   - 超过 24 小时会被自动驳回，要重新提交。
   - 你在进度档案里记下初审通过的时间，并提醒用户。
3. 通管局审核：1～20 个工作日。
4. 下发备案号。之后备案号会自动显示在小程序的「更多资料」页，不用自己挂。

**时长**：官方写情况二约 10～30 个工作日；实测时流程指引页写的是 3～10 个工作日。两处不一致，按官方的较长时长给用户预期。

**上线后**：游戏名称、负责人、联系方式变了，都要及时变更备案；不及时变更属于违规（[运营规范](https://developers.weixin.qq.com/minigame/product/) 2.5.35）`[官方]`。
